# Task 2 - Chatbot for FAQs

This project is an FAQ chatbot developed using Python and NLP.

## Features

- Answers frequently asked questions.
- Uses NLP techniques for text processing.
- Matches user questions with the most relevant FAQ.
- Provides the best matching answer.
- Simple and user-friendly interface.

## Technologies Used

- Python
- Streamlit
- NLTK
- Scikit-learn

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt

Run the application:

```bash
streamlit run app.py
```
